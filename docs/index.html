The BMM symmetrising trace conjecture for all exceptional complex reflection groups

Eirini Chavli, Maria Chlouveraki, Götz Pfeiffer, Kostas Psaromiligkos

We prove the symmetrising trace conjecture of Broué, Malle and Michel for the generic Hecke algebras of all exceptional complex reflection groups. A key ingredient is a new family of bases, constructed via breadth-first search, which generalise the standard basis of an Iwahori–Hecke algebra. These bases provide a uniform proof of the freeness conjecture of Broué, Malle and Rouquier for these groups. The verification for each group reduces to a finite computation, carried out using programs developed with the assistance of a large language model.

This site holds the programs of the paper, their input data, and their complete output. Each program writes a record, a text file that lists every identity it tests and the result; all records are included, so every result can be checked without running anything. The pages below show the bases and one coset table in detail.

The proof at a glance

The rows are the three parts of the proof; the columns are the rings over which the computations are carried out. Modular computations only select the candidates. The verifications are exact computations over R̄(W), where every constant term as,0 of a Hecke relation is 1, and Theorem 3.10, which relies on the grading of Broué, Malle and Michel, lifts their conclusions to R(W).

Running the programs

The programs need Julia 1.12 and the package Chevie 0.1.11; every other package is in Julia’s standard library. From the folder of the programs, install the pinned environment once, then run:

julia --project=. -e 'import Pkg; Pkg.instantiate()'   # once: Chevie 0.1.11 and its dependencies
julia --project=. programs/bmm_proof.jl G4             # about 15 s; rewrites G4/3_bmm_proof.txt
./run.sh G4                                            # the same, niced, with the threads and memory cap of the group file
./run.sh G20 all                                       # every step of one group

Running a program overwrites its record; only dates and times should differ from the shipped version. For G4–G29 each program takes between 10 s and 3 min, except the proof for G19 (16 min). The proofs for G31, G32 and G33 take about 11 min, 16 min and under a minute. The proof for G34 took 30 h and 13 GB of memory: run it with ./run.sh G34 all on a machine with 16 GB (its group file sets the memory cap and Julia’s heap-size hint). Its record was written across two resumptions from a checkpoint, with small changes of the programs in between that change no value (README, Section 7).
