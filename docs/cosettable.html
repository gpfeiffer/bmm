The coset table of G4, step by step

Example 4.8 of the paper, replayed from the program that the computations use.

The breadth-first basis of H(G4) is BFSo = {1, s1, s12}·{w1, …, w8}, where w1, …, w8 are the words of the coset tree of P = ⟨s1⟩. Its coset table gives each product wiσ as a combination of the wj with coefficients in H(P). Once the table is complete, the span of BFSo is a right ideal containing 1, so BFSo is a basis.

This page runs the program G4/cosettable04.txt one command at a time, and recomputes every entry with symbolic parameters, the Hecke relation being s3 = a2s2 + a1s + a0 for s = s1, s2, with a0 invertible. (The group file and the records of G4 call these parameters c0, c1, c2, and the programs compute with c0 = 1; this page keeps a0.) The 16 entries of the columns s1±1, s2±1 agree with those printed in the example. The program also fills the columns of the central element z = (s1s2)3, which the example omits; tick the box to include them.

The coset tree. Highlighted: the cosets in the current expression; outlined in red: the row of the current entry. Hover over a line of the computation to follow it.
