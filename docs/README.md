# Website

The web pages of the paper *The BMM symmetrising trace conjecture for all exceptional complex reflection groups*
(Chavli, Chlouveraki, Pfeiffer, Psaromiligkos).

| page | content |
|---|---|
| `index.html` | the paper's abstract, a map of the proof, what each record verifies, and every group with its records and data files |
| `bases.html` | for each group, the basis used in the proof: its coset trees, drawn interactively, and the list of its words |
| `bmm_programs.zip` | the programs, their libraries, the Julia environment, and every group's group file, data and records, for download |
| `bmm_programs/` | the same files, unzipped: the pages link to them |
| `cosettable.html` | Example 4.8 of the paper: the coset table of G4, replayed command by command from `G4/cosettable04.txt`, every entry recomputed with symbolic parameters |

The pages are static and self-contained: open `index.html` in a browser, or put this folder on any web server as it
is. They need no server-side code, no internet connection and no external library.

## Links to the programs

The pages link to the programs' files (records, group files, coset tables, `README.md`) in `bmm_programs/`, a copy of
the contents of the zip file. `config.js` sets that path:

    window.PROGRAMS = "bmm_programs/";

To link to another copy instead, e.g. in a repository whose root holds the programs (`README.md`, `lib/`,
`programs/`, `G4/`, …) and this folder as `Website/`, set it to `"../"`.

## Regenerating

The pages are generated by `figures/make_site.py` of the working folder `Programs_work`, from the templates in its
`figures/site/` and from the programs, data and records of `../Programs`:

    python3 figures/make_site.py ../Website      # from Programs_work

Rerun it after a record changes, for example when a long proof finishes: the table of groups on `index.html`, the
zip file and `bmm_programs/` show the records as they are at the time of the run. `config.js` and `bmm_programs/` are
rewritten at every run.
