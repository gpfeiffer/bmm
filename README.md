# The BMM Symmetrizing Trace Conjecture
### for all exceptional complex reflection groups

By Eirini Chavli, Maria Chlouveraki, Götz Pfeiffer and Kostas Psaromiligkos

We prove the symmetrising trace conjecture of Broué, Malle and Michel
for the generic Hecke algebras of all exceptional complex reflection
groups. A key ingredient is a new family of bases, constructed via
breadth-first search, which generalise the standard basis of an
Iwahori–Hecke algebra. These bases provide a uniform proof of the
freeness conjecture of Broué, Malle and Rouquier for these groups. The
verification for each group reduces to a finite computation, carried
out using programs developed with the assistance of a large language
model.
